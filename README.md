# Expense Tracker Dashboard

A responsive and theme-toggleable web app for tracking your daily, weekly, and monthly expenses and income. Built using **HTML**, **CSS**, and **JavaScript**, with local storage for persistence and Chart.js for visualizing your data.

---

## 🚀 Features

- ✅ Add income or expense transactions with a single toggle button
- ✅ Switch between **Daily**, **Weekly**, and **Monthly** history filters
- ✅ Visual representation of income vs expense via **Pie Chart**
- ✅ Light/Dark theme toggle for a pleasant user experience
- ✅ Responsive design – works across devices
- ✅ Data stored in browser **LocalStorage**

## 📦 How to Use
